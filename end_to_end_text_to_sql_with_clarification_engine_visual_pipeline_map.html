3. Deterministic Ambiguity Detector

Pure Python rule engine that inspects the extracted QuerySpec against semantic_registry.yaml. Catches column collisions, undefined metrics, missing date filters on large tables, and unmapped entity values without relying on LLM guessing.

The 2 Round-Trips Back to the User

Round-Trip 1: When Ambiguous (Pause & Clarify)

Node 4 calls interrupt() → FastAPI catches the paused checkpoint and returns status: "NEEDS_CLARIFICATION" → Streamlit renders clickable option buttons to the User → User clicks an option → Streamlit calls POST /api/resume → FastAPI wakes the graph at Node 6.

Round-Trip 2: Final Answer & Table Delivery

Node 10 executes the validated MySQL query → Node 11 generates the natural-language explanation + table → FastAPI returns status: "COMPLETED" JSON → Streamlit displays the explanation banner, interactive DataFrame, and expandable SQL code block to the User.
